# 趋势策略取代网格成为主策略

2026-09-30 的三步研究（`research/2026-09-30-trend-and-range.md`）显示：在 BTC、ETH、SOL 上，六票趋势投票加波动率调仓的 Trend Strategy 在几乎所有参数下风险调整后收益都高于持币；网格长期大致持平，任何「只在某种行情开网格」的规则都没能提高组合表现。决定以 Trend Strategy 为主策略，目标波动率 40%；网格代码保留，但同一账户同一时间只运行一种策略，两个 runner 都会拒绝在对方有持仓时启动，因为两个进程同时对账会互相误报。

## Considered Options

- 按行情识别切换策略（上涨持币、下跌空仓、震荡网格）：否决，回测比单纯趋势差一半，判断滞后，震荡期的网格仍在亏。
- 70% 趋势 + 30% 网格同时运行：否决，夏普没有提高，还要解决两个 runner 共享账户的对账。
- 单一均线（如 100 日）：否决，单参数结果随币种和参数剧烈变化，存在运气成分；六票平均更稳。
- 不调仓位（满仓跟随趋势）：用户选择了中档风险，40% 目标波动率把回测最大回撤从约 48% 降到约 33%。

## Consequences

- 重新引入了 ADR-0002 删掉的策略层概念，但只以 Book、Sleeve、Weight 的形式出现，没有通用的多策略组合层。
- 趋势策略超过一半的月份小亏，靠少数大行情赚钱；评估它需要以年为单位，而不是看某个月。
