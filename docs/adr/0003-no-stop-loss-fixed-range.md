# 网格不设止损，区间不移动

网格区间在启动时固定。价格跌破下沿时所有买单已成交，机器人满仓持有 BTC 并停止动作，不止损、不加仓；价格涨破上沿时持有全部 USDT，同样停止，不把区间上移。这是用户对「最差结果也能持有比特币」的定义：宁可踏空上涨，也不接受在高位重建仓位后回落被套，更不接受在低位割肉。任何一笔卖单只对应它下方一格的那笔买单，因此不存在亏本卖出。

## Considered Options

- 上移网格（上破后用卖出所得在更高区间重新布买单）：否决，把风险性质从「持有低位买的 BTC」变成「持有高位买的 BTC」。
- 保留永不卖出的底仓：暂不采用，网格可用资金减半；将来若想在上破后仍持有 BTC 可重新考虑。
- 下沿止损：否决，与「最差持有 BTC」直接矛盾。
